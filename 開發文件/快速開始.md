## ⚠️ 常見問題

### Q1: 啟動時顯示"找不到 Python"

**原因**：Python 未安裝或未加入 PATH

**解決**：
1. 下載 Python 3.7+：https://www.python.org/downloads/
2. 安裝時勾選 ✓ **Add Python to PATH**
3. 重新啟動 START.bat

### Q2: 運行時出現 API 錯誤

```
❌ emotion_analyzer: ❌
```

**原因**：.env 中 API 密鑰不正確或遺漏

**解決**：
1. 編輯 .env 文件
2. 檢查密鑰是否正確複製
3. 確認沒有多餘空格

### Q3: 網絡速度慢

**原因**：API 延遲或網絡不穩定

**預期延遲**：
- 第 1 批：10-15 秒（首次初始化）
- 第 2+ 批：5-8 秒（有緩存）
