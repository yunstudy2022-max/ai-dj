# claudio.fm 项目完整概述

## 📖 核心愿景
**claudio.fm** — 深夜、刻意、intentional 的 AI DJ 电台

一个由 AI 驱动的 24 小时无人值守直播电台，通过实时分析 YouTube 直播聊天室观众的情绪，自动生成温暖的 DJ 语音回应和精心生成的背景音乐，为深夜的加班族、失眠者、独处者提供情感陪伴。

## 🎭 核心设定
- **DJ 名字**：Claudio
- **个性**：内敛、有品味、擅长观察人类情感
- **美学**：Wabi-sabi 侘寂 + 底片颗粒 + 黑胶唱片
- **目标听众**：深夜 23:00-03:00 的孤独个体

## 🕐 三大时段人设

### 18:00-21:00【晚安下班了】
- **Vibe**：温暖、卸下装备、过渡期放松
- **语气**：活力充沛、充满陪伴感
- **选曲**：Jazzhop（节奏稍快）
- **话题焦点**：今天的小事、晚餐、工作吐槽

### 21:00-00:00【深夜吧檯】
- **Vibe**：故事感、微醺、大人时间
- **语气**：低沉、话不多但句句见血
- **选曲**：Lofi + 萨克斯风 + 微弱底噪
- **话题焦点**：感情、迷茫、深刻回忆

### 00:00-03:00【I人的时光】
- **Vibe**：绝对独处、无压力陪伴
- **语气**：轻声细语、极度内敛
- **选曲**：Ambient 环境音 + 极慢鋼琴
- **话题焦点**：无意义呢喃、失眠状态

## 💰 商业模式（SaaS化）

### 目标客群
1. **创作者**（B2C）：YouTube、Twitch、Podcast 主
2. **实体店**（B2B）：咖啡厅、酒吧、青旅、共享办公室

### 定价分级
- **Free**：1小时/天 + 浮水印
- **Pro（$29-49/月）**：24小时 + 自定义DJ名字 + 多个视觉版型
- **Business（$99+/月）**：Voice Cloning + 自定义广告 + 数据分析

## 🛠️ 技术核心
- **大脑**：Claude 3.5 Sonnet（情感分析 + 文案生成）
- **嘴巴**：ElevenLabs（自然情感语音合成）
- **乐器**：Suno API（AI音乐生成）
- **舞台**：React UI + OBS + YouTube Live
- **输入**：YouTube Live Chat API

## 📊 三阶段发展

### Phase 1（1-3周）— MVP验证
- 前端UI完成（✅）
- 后端核心引擎（⏳）
- 本地2小时测试

### Phase 2（1-2月）— 全自动化
- AI Agent接管
- 时段切换 + 容错系统
- 24小时无人值守运行

### Phase 3（3-6月）— 商业化
- 常客记忆系统
- 短视频自动生成
- 广告自动穿插

## 🔐 护城河
1. **品味UI封装**：工程师能写出功能，但做不出这种美感
2. **不间断排程引擎**：处理API延迟、超时、错误的复杂系统
3. **情感算法**：能精准捕捉深夜听众的心理状态

## 📝 下一步
优先完成Phase 1 MVP，证明系统可行性后再考虑商业化。
